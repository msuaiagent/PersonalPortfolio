# 💼 AI Club — Week 3  
## Environment Setup for Next.js Portfolio Project

---

# 🎯 Goal of Today (Before We Build Anything)

Before generating a portfolio site, you MUST have:

- Node.js installed
- npm working
- Git configured
- VS Code working
- A working Next.js development server

If your environment is not correct, you cannot proceed.

We are building like professionals.

---

# 🧠 Step 0 — Verify Node.js Installation

Go to:

https://nodejs.org/

Download the **LTS (Long Term Support)** version.

Install it.

Then verify in VS-Code terminal:

```bash
node -v
````

You should see something like:

```
v18.x.x
```

Then check npm:
 (in VS-code terminal)
```bash
npm -v
```

If both commands return versions, you are ready.

If not — fix this before continuing.

---

# 🧠 Step 1 — Verify Git Installation

In terminal:

```bash
git --version
```

If this fails:

Download Git:
[https://git-scm.com/downloads](https://git-scm.com/downloads)

You must have Git working.

---

# 🧠 Step 2 — Install VS Code Extensions (Required)

Open VS Code.

Install:

* ES7+ React/Redux Snippets
* Prettier
* Tailwind CSS IntelliSense (if using Tailwind later)
* GitLens (optional but recommended)

---

# 🧠 Step 3 — Create Your Next.js Project

In your terminal, run:

```bash
npx create-next-app@latest portfolio-site
```

You will be prompted.

Choose:

* ✔ TypeScript (recommended)
* ✔ ESLint
* ✔ App Router
* ✔ src/ directory (optional but recommended)
* ✔ Tailwind (optional but recommended)
* ✔ Use npm

Let installation complete.

---

# 🧠 Step 4 — Run the Development Server

Navigate into the folder:

```bash
cd portfolio-site
```

Start development server:

```bash
npm run dev
```

Open browser:

[http://localhost:3000](http://localhost:3000)

If you see the Next.js starter page:

Your environment is working.

If not — stop and fix.

---

# 🧠 Step 5 — Initialize Git Properly

Inside your project:

```bash
git init
git add .
git commit -m "Initial Next.js setup"
```

Then create a GitHub repo:

```
portfolio-site
```

Push it.

You now have:

* Version control
* Framework
* Dev server
* Professional setup

---
